# Contributor Guidelines

## Becoming a Contributor

### Application Process

1. Create an account on Veeranjali
2. Navigate to Settings > Contributor Application
3. Fill out the application form:
   - Explain why you want to contribute
   - Describe any relevant experience
   - Provide supporting links if available
4. Wait for admin review

### What We Look For

- Genuine interest in preserving memories
- Research skills
- Attention to detail
- Respect for privacy and dignity
- Commitment to accuracy

## Submission Guidelines

### Before You Start

1. Search the archive to avoid duplicates
2. Gather all available sources
3. Prepare supporting documentation
4. Review the Editorial Guidelines

### Required Information

Every submission must include:

- Full name of the person
- Force/organization
- Rank
- Biographical details
- Service history
- At least one verifiable source

### Writing Guidelines

**Tone**
- Respectful and dignified
- Factual and objective
- Clear and accessible

**Language**
- Use appropriate terminology
- Avoid sensationalism
- Be precise with dates and facts

**Structure**
- Start with a brief summary
- Provide chronological biography
- Include service history
- Add family details only if appropriate
- End with circumstances and legacy

### Source Requirements

Every claim must be sourced:

- Official records (preferred)
- News articles from reputable sources
- Published books
- Academic publications
- Family records (with verification)

Format your sources:
```
Title: [Article/Document Title]
Author: [Author Name]
Publisher: [Publication Name]
Date: [Publication Date]
URL: [Link if available]
Accessed: [Date you accessed it]
```

### Privacy Considerations

**Do NOT Include:**
- Private addresses
- Phone numbers
- Government ID numbers
- Financial information
- Names of minor children
- Graphic descriptions

**Include Only With Consent:**
- Names of surviving family members
- Personal photographs
- Private correspondence

## Submission Workflow

1. **Draft** - Create and save your draft
2. **Submit** - Submit for review when ready
3. **Review** - Admin reviews your submission
4. **Changes** - Make requested changes if needed
5. **Approval** - Admin approves
6. **Publication** - Story goes live

## Tips for Great Submissions

1. **Research Thoroughly**
   - Multiple sources
   - Cross-verify facts
   - Check dates carefully

2. **Write Clearly**
   - Simple language
   - Short paragraphs
   - Logical flow

3. **Be Respectful**
   - Focus on facts
   - Avoid speculation
   - Consider family feelings

4. **Document Everything**
   - Keep source links
   - Note where you found each fact
   - Save screenshots if needed

5. **Ask Questions**
   - Contact admins if unsure
   - Clarify guidelines
   - Seek feedback

## After Publication

- Monitor for corrections
- Respond to family inquiries
- Update if new information emerges
- Thank sources and contributors
